# 주문·출고 v0.1 검증 기록

검증일: 2026-10-11. 대상: Starter Kit 전용 로컬 앱 3002 / PostgreSQL 5433.
새 고객 환경이나 외부 배포는 생성하지 않았다.

| 경계 | 결과 | 근거 |

| API → DB | 통과 | 서버 합계 30.63 검증, 상태/합계 변조 거부, 범위 초과 시 이력 플래그 롤백 |

| 권한·경합 | 통과 | USER 확인 취소·확인 주문 취소·삭제 403, 동시 확인/출고 200+409, Shipment 1건 |
| 보존·감사 | 통과 | 기준정보 변경 후 스냅샷 유지, 최초 확인 이력 유지, 상태별 감사 로그 순서 확인 |
| 삭제 정책 | 통과 | 미확인 접수 주문만 ADMIN 삭제, 삭제 후 거래처·품목 사용 이력 제한 유지 |

| 기존 Core 회귀 | 통과 | 로그인·로그아웃·가입·사용자 CRUD·Task CRUD·권한 차단 |
| 데모 초기화 | 통과 | 보호 조건 단위 테스트, 트랜잭션 내 재생성/Core 보존 확인 후 전체 롤백 |

## 실행 결과

- lint: 통과
- TypeScript: 통과
- 단위 테스트: 19개 통과
- 브라우저 E2E: 4개 시나리오 통과 (1.2분)
- Production build: 통과
- Health endpoint: HTTP 200
- 데스크톱 업무 현황·390px 모바일 주문 목록 확인: 브라우저 pageerror 0건, 페이지 가로 넘침 없음
- 커밋 대상 검사: 실제 Auth 시크릿 일치 0건, 비공개 환경 파일 0건 (`.env.example`만 포함)
- 테스트 거래처·품목·주문·사용자·Task·업무 감사 로그: 잔여 0건
- 데모 샘플: 접수·확인·출고 주문 각 1건
- 기존 서비스와 DB 컨테이너 시작 시각 유지, 3000/3001 포트 유지
- C: 여유 약 11GB. 이미지 다운로드·기존 컨테이너 재시작 없음

확인된 실패는 수정 후 재검증했다: Next cacheComponents와 route runtime 설정 충돌,
선택 항목의 접근성 이름 불일치. 실패를 숨기거나 권한 검증을 완화하지 않았다.

## 완료와 미실행 구분

업무 기능·초기화 CLI와 관련 검증은 구현 범위다. 실제 영구 초기화는 실행하지 않았고
CLI 초기화 테스트는 롤백했다. 샘플 추가는 기존 데이터를 유지하는 seed로만 수행했다.
호스트 스케줄러 등록·인터넷 배포·고객사 복제는 실행하지 않았다.

`pnpm audit --prod`는 **통과가 아니다**. 기존 Prisma 경로에 high 2건·moderate 1건이 남는다.
신규 ExcelJS의 uuid 경고는 호환 override 후 해소했다. 인터넷 공개 전 의존성 업데이트의
호환성 검증, HTTPS·요청 제한·정기 초기화·백업·실패 알림 구성이 필요하다.
